部署与权限

自启动：Windows / macOS / Linux

Windows：写入当前用户的启动文件夹，下次登录后运行。若提示权限不足，可在任务计划程序中创建“登录时”任务，以当前用户运行 Python 和本服务，不需要最高权限。

macOS（Intel / Apple Silicon）：写入 ~/Library/LaunchAgents/org.research.monitor.plist，下次登录加载。在系统设置 → 通用 → 登录项中允许后台运行；若被系统阻止，请手动批准。

Linux：创建并启用 systemd 用户服务 research-sentinel.service。无图形登录时自动启动，需要管理员运行 loginctl enable-linger 用户名。没有 systemd 的系统请由管理员使用现有服务管理器运行下方命令。

自启动运行命令：


        

        
网络访问与防火墙
          
开启后监听全部 IPv4 网卡；关闭后仅监听 127.0.0.1。关闭时远程页面会断开，本机页面不受影响。此服务没有账号认证，只应开放给可信设备。

          
Windows：高级防火墙 → 入站规则 → 新建端口规则 → TCP，下方显示的服务端口；将来源限制为你的局域网网段或指定 Tailscale 设备。

          
Linux：由管理员在 ufw / firewalld 中仅放行可信来源到服务端口。macOS：系统设置 → 网络 → 防火墙 → 选项，允许对应 Python 解释器接收入站连接。

          
Tailscale：新增目标为此设备、端口为 tcp:服务端口的 grant，来源选择需要访问的账号或设备。规则不会代替本机服务监听和防火墙配置。

          

        

        
Python 进度与断点续跑
          
自动发现当前项目目录内的 Python 脚本或 python -m 任务，不接管交互式控制台、内核或监控服务自身。可在任务详情中指定已有日志与结果目录。

          
Python 脚本可通过 research_progress.report(project, completed, total) 报告进度；保存结果后再传入 state="completed"。不能判断退出原因时记录为“退出状态未知”，不无限重启。重启重放原命令，是否从 checkpoint 继续由脚本实现。

          
内存达到任一保护阈值，会关闭所有自动续跑并取消待执行重启，不终止正在运行的计算。内存恢复后需逐任务重新开启。
